The full code is in the file xyz-fulfillment.html. The whole application is that one file, so you don't need to install anything.

How to run it

Download xyz-fulfillment.html from the file card.
Double-click it. It opens in your default browser (Chrome, Edge, Firefox or Safari all work).
That's it. The app runs fully in your browser and needs no internet, server or database.

If you want to edit or customize it

Open the file in any text editor, such as VS Code or Notepad.
Edit and save, then refresh the browser tab to see your changes.
